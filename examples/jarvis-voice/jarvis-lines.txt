# Jarvis - full announcement script for Dreame/MOVA/Trouver vacuums
# 593 lines, covering every real (non-silent) announcement in the catalog.
#
# This is TEXT ONLY. No audio is included or linked here - see
# ../../examples/jarvis-voice/README.md for why, and for notes on
# generating audio for this legally, whichever voice you use.
#
# HOW TO USE THIS FILE
#   1. In the app: Custom Voices -> Create Custom Pack ... -> name it
#      "Jarvis", start as a COPY of an existing dialect (e.g. Bavarian)
#      so every ID below already exists in the package (this file only
#      OVERRIDES ids, it can't create brand new ones).
#   2. Custom Voices -> Import Texts from File -> pick this file.
#   3. Only text after the SECOND "|" counts. Lines starting with # and
#      blank lines are ignored. Nothing here touches the middle column.
#   4. Generate audio for each line with whichever voice you're legally
#      entitled to use (see the README next to this file), one file per
#      line, named "<id>.<ext>" (id must be the first number in the
#      filename, extension can be .ogg/.wav/.mp3/.m4a/.aac/.flac/.opus/.wma).
#   5. Collect them in one folder, then use "Import Recordings ..." in
#      the app to bulk-assign them to this package.
#
# Skipped on purpose: ids that are pure tones/beeps with no real content,
# and a handful the source transcription couldn't make out at all
# (0, 11, 78, 200, 303, 436, 488, 675, 686, 687, 688, 714, 721, 730, 751,
#  776, 803, 825, 856, 858, 859, 863, 864). Those stay on the stock voice.
